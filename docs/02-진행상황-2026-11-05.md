## 3. 05 장애물 정지 (11-03 ~ 11-05)

- Codex 리뷰 24건 → 조원 결정 4가지 (자동 재출발 유지 · 뜻 모르는 초음파 값은 출발 허락에서 뺌 · I2C 막힘은 한계로 · 다리 시험은 모형으로) + Claude 추천 16개 승인.

- 동작: 라인 중 **15cm 이하 → 잠깐 멈춤**(빨간 불 · 삐) → 20cm 넘음이 **1초** → 출발. 줄이 안 보이면 **옆걸음 찾기**(왼쪽 약 1cm → 오른쪽 약 2cm · 속도 55) · `1111`이면 라인 끔.

## 4. 06 사람 · STOP 표지판 (11-05)

- 모델: Hugging Face **`Ultralytics/YOLO26`의 `yolo26n.pt`** → 노트북에서 ONNX(320 · 640 · opset 12)로 변환 · 지문이 HF 공식 값과 같음 확인 · 라이선스 AGPL-3.0 (`models/README.md`).
- 라즈봇 OpenCV 4.10: 320 **24.4장/초** · 640 5.7장/초 (예전 YOLO11n 320은 약 16장/초).
- 80가지 중 **`person`(0) · `stop sign`(11)만** 골라 씀.
- 규칙 (라인 중에만): **사람 = 보이는 동안 멈춤 · 안 보인 지 1초 뒤 출발** · **STOP 표지판 = 3초 멈춤 → 출발 · 그 뒤 5초 무시** · 확신도 **0.65** · 연속 2번 · 인식이 멈추면(결과 1초 넘게 오래됨) 「사람 없음」으로 보지 않고 멈춤.
- 화면: 카메라 위 상자 · 이름 · 빨간 STOP · 「인식 멈춤」.
