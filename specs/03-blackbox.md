## 목표
라즈봇 프로그램이 켜져 있는 동안 카메라 화면을 **계속 녹화**해서, 나중에 「무슨 일이 있었는지」 영상으로 돌려 볼 수 있게 한다.
**가장 중요한 조건: 녹화가 바퀴를 멈추는 길을 절대 막거나 늦추지 않는다.**

## 왜
- 자율주행(07)을 시험하다 부딪히거나 이상하게 움직였을 때, 그 순간 라즈봇이 무엇을 봤는지 확인해야 원인을 찾는다.
- 라즈봇 시점의 참고 영상이 된다. (정지 시간 같은 **측정은 지금처럼 바깥에서 찍은 영상으로** 한다 — 블박은 손과 바퀴가 안 보인다.)

|---|---|---|

| ● 녹화 중 (영상 없음) | 카메라 장면이 0.3초 넘게 없어 「영상 없음」 화면을 쓰는 중 | 새 장면 → 녹화 중 |
| ■ 녹화 멈춤 | 쓰기 실패 · 10초 뒤 다시 시도 (3번까지) | 성공 → 녹화 중 · 3번 실패 → 녹화 안 함 |

- 화면에 보여 주는 값(상태 · 지금 파일 · 폴더 용량 · 버린 장면 수)은 블박 스레드가 **메모리에 적어 둔 값**만 쓴다. 웹 요청을 처리하면서 폴더를 훑거나 블박을 기다리지 않는다.

## 안전
- 블박은 바퀴를 움직이지 않는다. 대신 **바퀴를 멈추는 길을 막으면 안 된다:**
  - 블박은 **카메라 잠금을 잡지 않는다.** 카메라 스레드가 장면을 받으면 잠금 밖에서 블박 대기 줄(최대 5장)에 **넣어 보기만** 하고, 꽉 차 있으면 그 장면을 버리고 바로 다음으로 간다.
  - 시각 그리기 · 압축 · 파일 쓰기 · 지우기는 모두 블박 스레드에서만 한다. 블박 스레드가 멈춰도 대기 줄이 꽉 차서 장면을 버릴 뿐, 메모리가 계속 늘지 않는다.
  - 블박의 「카메라에서 장면 받기」는 카메라가 살아 있다는 표시(영상 나이)를 바꾸지 않는다.
- 저장 공간: 블박 폴더 2GB · SD 빈 공간 1GB 아래면 녹화 멈춤. 블박이 지우는 것은 `results/blackbox/` 안의 블박 파일뿐.

## 바꿔 볼 값
- 파일 길이 3분 → 1분 · 5분
- 용량 한도 2GB → 1GB · 4GB
- 초당 장 수 10 → 15 (CPU · 온도 · 제어 간격 비교)

## 설계 — Claude 제안 (조원 승인 2026-11-03 · 리뷰 반영 부분은 조원 확인 필요)

### 흐름
```
카메라 스레드 (webabb.py, 640x480)
  ├─ JPEG 압축 → 웹 화면 전송 · 영상 나이 (지금 그대로, 잠금은 바꿔 끼우는 순간만)
  └─ 원본 장면 + 받은 시각 ──(잠금 밖 · 넣어 보기만 · 꽉 차면 버림)──▶ 블박 대기 줄 (최대 5장)
                                                                          │
블박 스레드 (missions/blackbox.py)  ◀─────────────────────────────────────┘
  0.1초 칸마다: 새 장면 or 「영상 없음」 → 시각 찍기 → 파일 쓰기
  results/blackbox/2026-11-03_16-42-07_r3f9a_001.avi  + 같은 이름 .csv (장면 번호 · 받은 시각)
```
- **카메라 루프 고침:** 지금은 사진 처리 뒤 0.1초를 또 쉬어 실제로 초당 10장이 안 나온다 → 「다음 칸 시각까지만」 쉬도록 바꾼다 (웹 화면에도 같은 이득).
- **파일 이름:** `날짜_시각_실행번호_순번.avi` — 실행번호는 프로그램 켤 때마다 새로 뽑는 짧은 글자, 순번은 001부터. **같은 이름이 있으면 절대 덮어쓰지 않는다.** 오래된 순서는 이름의 시각이 아니라 **실행번호별 순번 + 파일을 만든 순서 기록**으로 정한다 (시계가 뒤로 바뀌어도 순서가 안 꼬이게).
- **파일 형식:** `.avi` (MJPG). 다 쓴 파일은 정상 재생, 쓰다 끊긴 마지막 파일은 「열리면 다행」(위 성공 기준).
- **재사용 (07):** `missions/blackbox.py`는 카메라를 직접 열지 않는다. 「장면 + 받은 시각을 넣어 주면 녹화한다」만 한다. 카메라는 그것을 연 프로그램 하나만 갖는다. 같은 폴더를 두 프로그램이 동시에 관리하지 않도록 **폴더 잠금 파일**을 둔다(이미 잠겨 있으면 녹화 안 함 · 화면에 표시).
- **끝낼 때:** 지금 웹 조종의 끝내기 순서(네 바퀴 0 → 끝)에 「녹화 마무리 최대 1초」를 바퀴 정지 **뒤에** 넣는다.

## 만드는 순서
1. 바퀴 없이(`--dry`): MJPG 쓰기 확인 → 10분 녹화 · 재생 시간 · 파일 사이 빈틈 · 「영상 없음」 · 시각 확인
2. 깨뜨리는 시험(`--dry`): 일부러 느린 쓰기 · 용량 한도 낮추기 · SD 빈 공간 부족 흉내 · `kill -9` 3번 → 제어 간격 · 감시 개입 기록
3. 30분 켜 두고 온도 · 스로틀 기록
4. 웹 조종(상자 위)과 같이 켜서 손 뗌 · 비상정지 정지 시간이 녹화 없을 때와 같은지
