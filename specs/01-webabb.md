# 지시서 · 웹앱으로 조종하기 (webabb)

> 틀: `specs/00-template.md`. 「조원 결정」은 1조가 정한 것, 「Claude 추천」은 조원이 추천을 맡긴 값(조원 승인 2026-11-02)입니다.
> 모든 칸이 정해졌습니다 (2026-11-02).

## 목표
노트북 · 휴대폰 **웹 브라우저 화면**에서 버튼과 키보드로 라즈봇을 움직이고, 라즈봇 카메라 화면을 보면서 조종한다.

## 왜 (지금 방식의 불편함)
- `teleop.py`는 SSH 터미널 · 영어 입력 상태가 필요하다. 한글 상태면 키가 무시된다.
- 휴대폰으로는 조종할 수 없다.
- 키를 떼도 최대 0.6초 더 움직인다 (키 반복 방식의 한계, `log.md` 2026-11-02 참고).

### 멈추는 시간 추천 근거
- 2026-11-02 핫스팟 측정: ping 6~49 ms, 키 입력이 뭉쳐서 오는 간격 최대 0.17초.
- 버튼을 누르는 동안 브라우저가 **0.1초마다** 「계속 가」를 보내면, 0.4초 기준은 신호 3번을 연달아 놓쳐야 멈춘다 → 핫스팟이 잠깐 느려져도 끊기지 않을 여유.
- 정상일 때는 손을 떼는 순간 「정지」를 따로 보내므로 **0.4초까지 기다리지 않는다.** 0.4초는 신호를 놓쳤을 때의 안전장치.
- 지금 키보드 조종(최대 0.6초)보다 빨리 선다.

- 멈춤 · 출발 시간은 **버튼(또는 키)과 바퀴를 한 화면에 같이 찍은 영상**(초당 30장 → 한 장 약 0.033초 오차)으로 잰다. 기준과 0.033초 안쪽으로 가까우면 「경계」로 적고 다시 잰다.

## 안전
- **출발 · 가속은 서서히 (2026-11-06 조원 결정 「3번 바로 넣어」 · 값은 Claude 제안):** 바퀴 값을 **올릴 때만** 제어 주기(0.02초)마다 **최대 12씩** 올린다 (0 → 120 약 0.2초 · 0 → 60 약 0.1초). **줄이거나 멈출 때 · 방향이 바뀔 때 0으로 가는 것은 바로** 한다(안전). 수동 조종 · 라인 따라가기 모두 같은 곳에서 적용. 이유: 바닥에서 앞 · 뒤를 누르면 오른쪽 앞 바퀴만 도는 일이 있었는데, 상자 위에서는 한 번 보내기 · 계속 보내기 6번 모두 네 바퀴가 돌고 I2C 오류 0번 → 네 모터가 한꺼번에 출발하는 순간 전류 · 전압 문제로 추정.
- **라인 직진 전환 보정 (2026-11-06 리뷰 수정 요청):** 라인 판단의 목표가 네 바퀴 같은 양수이면, 바퀴별 +12 가속 후보 중 가장 작은 값으로 네 바퀴를 맞춘다. 회전에서 직진으로 바뀌어도 좌우 가속 차이를 만들지 않는다. 수동 조종과 라인의 꺾기·회전 출력은 기존 바퀴별 가속을 유지한다. 0 정지는 항상 즉시 보낸다. DRIVE 기록에는 목표와 실제 쓰기 값을 구분한다.

- 바퀴 속도: **처음 120** · 조절 범위 **40 ~ 150** (150은 프로젝트 한계라 넘지 않음 · Claude 추천) · 조절 단계 10
- 움직이는 범위: **버튼 · 키를 누르고 있는 동안만** 움직인다. 거리 제한은 따로 두지 않는다 (조원 결정)
- 프로그램이 끝나거나 오류가 나도 네 바퀴를 0으로 멈춘다 (AGENTS.md 수칙)
- 같은 핫스팟에 붙은 사람만 주소로 들어올 수 있다. 접속 비밀번호는 **걸지 않는다** (조원 결정) — 같은 핫스팟의 누구나 먼저 들어오면 조종할 수 있음

## 바꿔 볼 값
- 손을 뗀 뒤 안전장치 시간: 0.4초 → 0.3초 / 0.6초 — 끊김 없이 가는지 vs 얼마나 빨리 서는지
- 처음 속도 120 → 100 / 140
- 카메라 화면 크기 · 초당 장면 수 (조종 반응이 느려지는지 · 핫스팟 데이터)

### 구조

- 파일은 모두 이 폴더 안에 둔다: `missions/webabb.py` + `missions/webabb/` (화면 파일).

### 화면 구성
- 위: 카메라 화면
- 가운데: 방향 버튼 6개 (앞 · 뒤 · 옆왼 · 옆오 · 제자리 왼쪽 · 제자리 오른쪽) + 큰 **정지** 버튼
- 아래: **속도 조절기** (40 ~ 150, 처음 120) · 지금 속도 숫자 · 연결 상태 (조종 중 / 끊김)
- 휴대폰에서는 손가락으로 누르고 있는 동안 움직이게 (터치 지원)

### 동시에 누르기 표 (5번)
| 누른 것 | 움직임 | 바퀴 (왼앞, 왼뒤, 오앞, 오뒤) |
|---|---|---|
| 앞 + 오른쪽 | **앞 오른쪽 대각선** | + 0 0 + |
| 앞 + 왼쪽 | **앞 왼쪽 대각선** | 0 + + 0 |
| 뒤 + 오른쪽 | **뒤 오른쪽 대각선** | 0 − − 0 |
| 뒤 + 왼쪽 | **뒤 왼쪽 대각선** | − 0 0 − |
| 왼쪽 + 오른쪽 (다른 것과 함께여도) | **안 움직임** | 0 0 0 0 |
| 앞 + 뒤 (다른 것과 함께여도) | 안 움직임 (왼쪽+오른쪽과 같은 규칙으로 맞춤 · Claude) | 0 0 0 0 |
| 제자리 회전 + 다른 버튼 | 안 움직임 (회전은 혼자 눌렀을 때만 · Claude) | 0 0 0 0 |
| 정지 버튼 | 누르고 있는 것 모두 풀고 정지 · 다시 누르기 전까지 안 움직임 | 0 0 0 0 |
- 키보드도 같음: W+D = 앞 오른쪽, W+A = 앞 왼쪽, S+D = 뒤 오른쪽, S+A = 뒤 왼쪽.
- 화면 버튼과 키보드를 섞어 눌러도 「지금 눌려 있는 것 전체」로 위 표를 따른다. 손가락 · 키 하나를 떼면 남은 것으로 다시 정한다.
