# 지시서 02 · 사람 따라가기

> **보류 (2026-11-03)** — 조원 결정으로 03 블박 · 04 라인트레이서 · 05 장애물 정지 · 06 사람 STOP 표시 · 07 자율주행을 먼저 한다. 이 지시서는 그 뒤에 다시 본다.

> 틀: `specs/00-template.md`. 모든 칸은 1조가 정했습니다 (2026-11-03, 질문으로 결정). 「설계」는 Claude 제안을 조원이 고른 것.

## 목표
라즈봇 카메라로 **사람을 찾아**, 그 사람과 **50cm 거리**를 유지하며 따라간다. 사람을 놓치면 **멈춘다**.

## 왜
- 「보고(인식) → 판단(추적) → 움직임(제어)」이 이어진 **닫힌 루프**를 만들어, 기술 완성도를 보여 준다.
- 2026-11-03 측정: YOLO11n(입력 320, OpenCV DNN)이 라즈봇에서 **약 16장/초** (`docs/01-진행상황-2026-11-02.md` 참고) → 걷는 사람을 따라가기에 충분.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 따라가기 켜는 순간 | 화면에서 **가장 크게 보이는(가장 가까운) 사람**을 목표로 잡는다 |
| 사람이 여러 명 | **처음 잡은 사람을 계속** 따라간다 (위치로 이어서 추적) |
| 목표가 **60cm보다 멀다** | 앞으로 다가간다 |
| 목표가 **40~60cm** (50cm ± 10cm) | 앞뒤로 움직이지 않고 기다린다 |
| 목표가 **40cm보다 가깝다** | **뒤로 10cm 물러난다.** 물러난 뒤에도 목표가 인식되지 않으면 **멈춘다** |
| 목표가 화면 가운데 ±5% 안 | 좌우로 움직이지 않는다 |
| 목표가 가운데에서 5~20% 벗어남 | **옆으로 이동**(메카넘)해서 맞춘다 |
| 목표가 가운데에서 **20% 넘게** 벗어남 | **제자리 회전**으로 맞춘다 |
| **목표를 0.5초 동안 못 찾음** | **멈춘다** |
| 앞에 사람 아닌 물건이 **15cm 안** (초음파) | **멈춘다** |
| 켜기 · 끄기 | **웹 조종 화면(`webabb`)의 「따라가기」 버튼.** 정지 · 비상정지 · 수동 방향 버튼을 누르면 따라가기는 바로 꺼진다 |

## 성공 기준 (숫자로) — 「엄격하게」로 결정
| 무엇 | 기준 | 횟수 |
|---|---|---|
| 유지 거리 | 사람이 멈춰 있을 때 **40~60cm**에서 멈춤 | **10번 중 10번** |
| 따라오기 | 사람이 천천히 걸어갈 때 놓치지 않고 따라옴 (2m × 2m 공간 안) | **5번 중 5번** |
| 놓치면 멈춤 | 사람이 화면 밖으로 나가면 0.5초 + 정지까지 **1초 안에** 멈춤 | **10번 중 10번** |
| 너무 가까움 | 40cm 안으로 다가오면 뒤로 10cm 물러남 · 그 뒤 못 찾으면 멈춤 | **5번 중 5번** |
| 장애물 | 사람 아닌 물건 15cm 앞에서 멈춤 | **5번 중 5번** |
| 여러 명 | 두 번째 사람이 지나가도 처음 사람을 계속 따라감 | **5번 중 4번 이상** |
| 충돌 | 사람 · 물건과 부딪힘 | **0번** |

- 시간 · 거리는 라즈봇과 사람(줄자 바닥 표시)을 한 화면에 찍은 영상으로 잰다.

## 안전
- 속도: **처음 전진 60 · 회전 50**으로 시험 → 잘 되면 **전진 80 · 회전 60**으로 올림 (프로젝트 한계 150 안)
- 뒤로 물러나기: 10cm만 · 같은 속도 한계
- 시험 공간: 바닥 **2m × 2m · 사방 1m 비움**
- 프로그램이 끝나거나 오류가 나도 네 바퀴 0 (AGENTS.md)
- 웹 조종의 안전 구조(제어 스레드 하나 · 정지 실패 잠금 · 감시 스레드 · 영상 0.8초 멈춤 정지 · 비상정지)를 그대로 쓴다
- 쿨러 없음: 60초 연속 인식에 30 → 62°C. 오래 시험할 때 온도를 같이 기록하고, 80°C에 가까우면 쉰다

## 바꿔 볼 값
- 유지 거리 50cm → 40 · 70cm
- 놓쳤다고 볼 시간 0.5초 → 0.3 · 1초
- 옆 이동 → 회전 바뀌는 기준 20% → 10 · 30%
- 인식 입력 크기 320 → 640 (멀리 있는 사람 · 대신 5장/초)
- 속도 60/50 → 80/60

## 설계 (조원이 고른 안)

### 흐름
```
카메라 640x480 → YOLO11n(320, OpenCV DNN) → 「person」 박스들
   → 목표 고르기: 켤 때 가장 큰 박스 · 그 뒤로는 이전 위치와 가장 많이 겹치는 박스
   → 좌우 오차 = 박스 중심 - 화면 중심 (화면 폭 대비 %)
        ±5% 안: 그대로 · 5~20%: 옆 이동 · 20% 넘음: 제자리 회전
   → 거리 = 초음파(목표가 정면일 때) / 박스 높이로 추정 (50cm에서 미리 맞춤)
        > 60cm: 전진 · 40~60cm: 정지 · < 40cm: 뒤로 10cm
   → 웹 조종의 제어 스레드(바퀴에 쓰는 유일한 곳)에 「원하는 움직임」 전달
```
- 인식은 초당 약 10장으로 제한 (웹 카메라 화면 전송과 CPU를 나눠 씀).
- 웹 화면 카메라 위에 목표 박스(초록) · 다른 사람 박스(회색)와 거리 · 상태를 표시.

### 파일
- `missions/webabb.py`에 「따라가기 모드」 추가 · 인식 부분은 `missions/follow/` 로 나눔
- 모델: `models/yolo11n_320.onnx` (라즈봇에 있음 · 라즈봇에 추가 설치 없음)

## 만드는 순서
1. **바퀴 없이(`--dry`)**: 카메라 + 인식 + 「이렇게 움직이겠다」만 기록 · 웹 화면에 박스 표시 · 온도 기록
2. 거리 맞추기: 사람이 40 · 50 · 60cm에 섰을 때 초음파 값 · 박스 높이 기록
3. **상자 위**(바퀴가 바닥에 안 닿음): 사람이 좌우 · 앞뒤로 움직일 때 바퀴 방향이 규칙표대로인지
4. **바닥**(2m × 2m · 사방 1m): 속도 60/50 → 성공 기준 표 → 잘 되면 80/60
