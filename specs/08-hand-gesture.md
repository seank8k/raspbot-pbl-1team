# 지시서 08 · 손 모양 명령

> 틀: `specs/00-template.md`. 「조원 결정」은 1조가 정한 것, 「(질문)」은 아직 조원이 정하지 않은 칸 — 정해지기 전에는 바퀴에 연결하지 않는다.
> 06(사람 · STOP 표지판)과 **따로 도는 두 번째 모델**로 만든다. 07 자율주행에서 합친다.

## 목표
라즈봇 카메라로 사람의 **손 모양 4가지**를 알아보고, 손 모양마다 정한 명령을 한다.

## 왜
- 웹 화면을 누르지 않고 손짓으로 라즈봇에게 명령하기 — 사람과 로봇이 함께 쓰는 기능.
- COCO 80가지에 손 모양이 없어서 **직접 학습한 모델**이 필요하다 → 데이터 · 학습 · 변환 · 라즈봇 실행까지 한 번에 해 보는 과제.

## 정해진 것
| 무엇 | 내용 | 누가 정함 |
|---|---|---|
| 손 모양 · 명령 | `palm`(보) = **출발** · `fist`(주먹) = **멈춤** · `like`(엄지척) = **빠르게** · `peace`(브이) = **사진 찍기** | 조원 결정 (2026-11-05) |
| 데이터 | **HaGRID** (https://github.com/hukenovs/hagrid) 의 `palm` · `fist` · `like` · `peace` + 같은 사진 속 `no_gesture`(명령 아닌 손) · 손 모양마다 학습 1,500장 · 검증 300장만 골라 씀 (전체 1.5TB는 무료 Colab에 안 들어감) | 조원 결정 (Colab 학습) · 장 수는 Claude 제안 |
| 학습 | **Colab 무료 GPU** · 기본 모델 **`yolo26n.pt`** · 입력 **320** (라즈봇에서 06 모델과 같이 돌리려고 작게) · 노트북 `tools/colab/train_gestures.ipynb` | 조원 결정 (Colab · 무료) · 모델 크기 · 입력은 Claude 제안 |
| 라즈봇 실행 | 학습한 모델을 노트북에서 받아 ONNX(opset 12)로 → 라즈봇 OpenCV DNN · 라즈봇에는 아무것도 설치 안 함 | AGENTS.md · 06과 같은 방법 |
| 06과 합치기 | 모델 두 개를 **따로** 돌린다 (06 YOLO26n COCO + 08 손 모양). 한 모델로 합치려면 손 사진 속 사람에게도 `person` 라벨이 필요해서 안 함 | 조원 결정 (2026-11-05) |

## 규칙표
| 상황 (언제) | 행동 (무엇을) | 누가 정함 |
|---|---|---|
| 손 모양이 보임 | 화면에 손 상자 · 이름 | **(질문) 확신도 몇 이상 · 연속 몇 번 보여야 「보임」인가** |
| `palm` → 출발 | **(질문) 무엇을 출발하나** (라인 따라가기를 켜나? 수동 앞으로? 속도 몇?) · 바퀴가 손짓만으로 움직이므로 **안전 규칙 필요** | 조원 결정 필요 |
| `fist` → 멈춤 | **(질문) 정지 버튼과 같게(라인 끔 · 다시 눌러야 출발)?** | 조원 결정 필요 |
| `like` → 빠르게 | **(질문) 몇에서 몇으로 · 최대 몇 (지시서 04 한계 80 · 프로젝트 150)** | 조원 결정 필요 |
| `peace` → 사진 찍기 | **(질문) 어디에 저장 · 몇 장 · 찍을 때 알림** (사람 얼굴 → 깃에 안 올림) | 조원 결정 필요 |
| 손이 여러 개 · 다른 사람 손 | **(질문) 누구 손을 따르나** | 조원 결정 필요 |
| `no_gesture`(그냥 손) | 아무것도 안 함 | Claude 제안 |

## 안전
- **손짓만으로 바퀴가 움직이게 하는 건 규칙표 (질문)이 정해진 뒤에만.** 그 전에는 화면 표시만 한다.
- 바퀴 시험은 AGENTS.md대로 (바닥 · 사방 1m · 전원 스위치 옆 사람).
- HaGRID 사진 · 우리가 찍은 손 사진에는 얼굴이 있다 → **깃에 올리지 않는다.** 데이터는 Colab 안에서만 쓴다.
- HaGRID 라이선스는 **CC BY-SA 4.0 변형** — 전용 라이선스(https://github.com/hukenovs/hagrid/blob/master/license/en_us.pdf)를 확인하고 출처를 남긴다.

## 바꿔 볼 값
- 장 수 1,500 / 300 → 3,000 / 500 (더 정확 · 받는 시간 늘어남)
- 입력 320 → 416 (멀리 있는 손 · 대신 느림)
- 학습 횟수(epochs) 60 → 100
- 라즈봇 카메라로 찍은 우리 손 사진 추가 (낮은 각도에 맞춤)

## 만드는 순서
1. Colab에서 `tools/colab/train_gestures.ipynb` 실행 → `gestures_yolo26n_320.onnx` · `gestures_best.pt` 받기
2. 노트북에서 `models/`에 넣고 지문 · 라벨 기록 → 라즈봇 OpenCV로 읽히는지 · 속도
3. 라즈봇 카메라 앞에서 손 모양 4가지 · 거리별 확인 (바퀴 안 씀)
4. 조원이 규칙표 (질문) 칸을 정함 → 이 지시서 고침
5. 웹 화면에 손 상자 · 이름 표시 → 그다음 명령 연결
