    **시나리오:** 비공개 제출 정책과 공개 요구가 충돌하거나, 출처·라이선스·모델 버전을 남기지 않습니다. YOLO26에는 공식 문서가 있지만, 최신 예제와 구버전 OpenCV 조합의 검증 자료가 충분하다고 볼 수 없습니다. 현재 공식 문서와 저장소에도 FLOPs 표기가 조금 달라 버전 없는 숫자 비교는 재현하기 어렵습니다.

    **고칠 방법:** 제출·배포 방식에 따른 라이선스 의무를 확인하고, 모델 SHA-256·내보내기 도구 버전·옵션·opset·출력 형태를 고정해야 합니다.

- **OpenCV 로딩·첫 추론·지속 추론:** 아래는 합성 입력의 **순수 추론 시험**입니다. 정확도·카메라·전후처리·웹 지연을 측정하지 않습니다. `MODEL`을 바꿔 같은 조건으로 비교합니다.

  ```bash
  MODEL=models/yolo11n_320.onnx /usr/bin/time -v python3 - <<'PY'
  import os, time
  import cv2
  import numpy as np

  cv2.setNumThreads(2)
  t = time.perf_counter()
  net = cv2.dnn.readNetFromONNX(os.environ["MODEL"])
  print("load_s", time.perf_counter() - t, flush=True)
  x = np.zeros((1, 3, 320, 320), np.float32)
  times = []
  end = time.perf_counter() + 60
  while time.perf_counter() < end:
      t = time.perf_counter()
      net.setInput(x)
      y = net.forward()
      times.append(time.perf_counter() - t)
      if len(times) == 1:
          print("first_s", times[-1], "shape", y.shape, flush=True)
  ms = np.array(times[1:]) * 1000
  print("ms p50/p95/p99/max", np.percentile(ms, [50, 95, 99, 100]))
  print("inference_fps", 1000 / ms.mean())
  PY
  ```

  スレッド数は1・2・4でも比較し、平均FPSだけでなくp99・最大値・最大RSSを残します。
